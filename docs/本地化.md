# 界面语言与新增翻译

在“设置 → 常规 → 界面语言”选择“跟随系统”或列表中的语言，点击保存后生效。取消不会保存或应用语言修改。设置字段为 `InterfaceLanguage`，空字符串表示跟随启动时的系统界面语言；旧配置没有该字段时自动使用此行为。

内置默认英文和简体中文两个界面资源包：`Strings.resx`（英文）与 `Strings.zh-CN.resx`（简体中文）。界面语言选择器提供“跟随系统”、English 与 简体中文。如需恢复更多语言，可在 `Libraries/NimCap.Screenshot.Core/Resources/` 重新加入 `Strings.<culture>.resx` 资源包，并在 `Services/LocalizationService.cs` 的 `AdditionalLanguages` 中登记；SDK 会自动生成对应的文化目录。

界面语言独立于 OCR 语言、翻译源语言和目标语言，也不改变系统数字解析格式。已有 XAML 控件及托盘菜单会刷新；操作进度和动态消息在下一次更新时使用新语言。用户输入、识别结果、分组名称、文件名和配置标识不会被翻译。

## 资源与引用

- 共享资源：`Libraries/NimCap.Screenshot.Core/Resources/Strings.resx`（默认英文）及同目录下的 `Strings.<culture>.resx`。
- NuGet：主程序引用 `WPFLocalizeExtension` 3.10.0；Core 层通过 .NET `ResourceManager` 读取同一套资源。
- XAML 使用完整资源路径，跨窗口及资源字典无需重复设置默认程序集：

```xml
xmlns:loc="http://wpflocalizeextension.codeplex.com"

<Button Content="{loc:Loc NimCap.Screenshot.Core:Resources.Strings:Save}" />
```

C# 使用 `NimCap.Screenshot.Localization.UiText.Get("Save")`。包含参数的完整句子使用 `UiText.Format("AboutVersion", version)`，对应资源值为 `Version {0}` / `版本 {0}`。避免拼接句子，翻译可以自由调整参数顺序；各语言的参数编号、对齐和格式应一致。

需要实时刷新的 C# 控件用 `LocalizationService.Bind(control, property, resourceKey)`，格式参数可作为后续参数传入。普通消息在展示时读取资源。不要在静态字段里缓存已经翻译的文字；模型标签和格式描述保存资源键并在访问时读取。

## 增加语言

1. 复制 `Strings.resx` 为 `Strings.<culture>.resx`，例如 `Strings.ja.resx` 或 `Strings.fr-FR.resx`。
2. 保留所有资源键，仅翻译 `value`。保留 `{0}` 等参数及格式，以及文件筛选器中的扩展名、协议名和模板字段。
3. 运行 `python scripts/validate-language-packs.py`，检查全部内置语言包的资源键、参数、模板字段及文件筛选器。
4. 正常构建或发布。SDK 自动生成文化目录中的 `NimCap.Screenshot.Core.resources.dll`；程序自动发现它并用语言本名显示在选择器中，无需修改窗口代码或维护额外语言列表。
5. 完整分发输出目录，包括语言子目录。检查长文案、按钮、工具提示与小窗口布局。

资源缺失时按 .NET 文化父级回退，最终使用默认英文。系统语言匹配已安装文化或其父级；没有精确中文包时使用简体中文，其他不支持的系统语言使用英文。新增精确语言包后优先使用该包。

录屏质量目前沿用已有配置中的 `流畅 / 标准 / 高清` 标识，显示标签独立翻译。不得将本地化后的 `ComboBoxItem.Content` 当作配置值，应使用 `Tag` 或稳定 ID。设置页导航同样使用稳定 Tag。

## 验证

维护者可运行 `python scripts/generate-language-packs.py` 补齐缺失的机器翻译包，或附加目标代码（如 `ja ko pt-PT`）仅生成部分语言。此命令会将内置英文界面文案发送到 Google 翻译，运行前须获得授权；不读取用户配置或截图。格式参数、模板字段及文件筛选器受保护，翻译缓存保存在 `.artifacts/language-cache`，中断后可以续跑。默认保留已有资源文件；加 `--overwrite` 可重新生成，使用前请备份人工修改过的译文。

```powershell
python scripts/validate-language-packs.py
dotnet build NimCap.Screenshot.csproj -c Release -o .artifacts/localization-build -m:1 /p:UseSharedCompilation=false
$localizationTest = Start-Process -FilePath '.artifacts/localization-build/NimCap.Screenshot.exe' -ArgumentList '--localization-self-test .artifacts/localization-test' -WindowStyle Hidden -Wait -PassThru
$localizationTest.ExitCode
Get-Content .artifacts/localization-test/localization-self-test.txt -Encoding UTF8
```

自检检查全部语言包的资源完整性、占位符、文件筛选器、语言选择和 WPF 标题，并生成各语言设置窗口的离屏 PNG。另检查系统语言匹配、英文回退、旧配置、语言 JSON 往返、未保存修改、质量标识、XAML / 托盘实时切换、菜单图标及模型名称，并生成中英文设置、识别、图片输出、录屏、长截图、编辑器与参数窗口的离屏 PNG。测试不保存用户配置、不注册全局快捷键、不发送翻译请求。
